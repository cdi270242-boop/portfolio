# E-Commerce Customer Analytics — End-to-End Portfolio Project

One end-to-end project: DummyJSON API → Python ETL pipeline → MySQL → SQL analysis → three Plotly dashboards.

## What it does
- Extracts products, users and carts (100 records each) from the DummyJSON API and loads them into MySQL (`Pipeline.ipynb`).
- Designs a four-table MySQL schema for customer segmentation (`customer_segmentation_setup.sql`, `customer_segmentation_additional_rows.sql`).
- Analyses the customer base in Python and SQL (`customer_segmentation_analysis.ipynb`).
- Reports the results as three interactive Plotly dashboards: Customer Segmentation, P&L, and Products (`01_segmentation_dashboard.ipynb`, `02_pl_dashboard.ipynb`, `03_products_dashboard.ipynb`).

## Key results (25-customer MySQL dataset — portfolio demo, DummyJSON + synthetic records)
- 25 customers, 46 orders, $7,433.47 in order revenue.
- VIP: 4 customers holding $8,855.50 of lifetime value — 50.6% of the $17,504.49 total. Loyal: 6 customers, $4,760.00.
- Electronics is the top category: $3,291.99 (44.3% of revenue), average order value $274.33.
- P&L is estimated (60% COGS / 15% operating-cost assumptions): 40% gross margin, 25% net margin. Peak month Oct 2024, $2,541.50 revenue.
